# Nisleida Morales — Portfolio

Personal portfolio of a Solutions Engineer, Geospatial Developer, and Urban Planner based in Berlin.

**Live site:** [urbanis.github.io](https://urbanis.github.io)

---

## About

This portfolio showcases my work at the intersection of urban planning, geospatial technology, and product design. It includes side projects, academic publications, career timeline, and credentials — available in English, Spanish, and German.

## Sections

- **Hero** — Introduction and roles
- **About** — Bio and experience stats
- **Skills** — Interactive Venn diagram of tech, urban planning, and design skills
- **Portfolio** — Side projects grouped by theme (Mobility Data, Behavior Research, Urban Design)
- **Publications** — Master's thesis, bachelor's thesis, and a peer-reviewed article
- **Credentials** — ArcGIS Pro and Cesium certifications, and contact info
- **Career** — Interactive map timeline across Venezuela, Argentina, and Germany
- **Blog** — Posts from LinkedIn and personal writing

## Built with

React 19 · TypeScript · Vite · Ant Design · Mapbox GL · motion (Framer Motion v12) · CSS Modules

**Tooling & CI:** Storybook · Vitest · ESLint · GitHub Actions (lint + test + build + deploy to GitHub Pages)
